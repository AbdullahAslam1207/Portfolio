# Abdullah Aslam: Portfolio

Personal portfolio site for Abdullah Aslam, Generative AI Engineer (RAG, LLM agents, voice AI).

Built with React, TypeScript, Vite and Tailwind CSS.

```sh
npm install
npm run dev     # local dev server
npm run build   # production build in dist/
```

Contact details live in `src/lib/contact.ts`. Experience, projects and skills content lives in the matching components under `src/components/`.
